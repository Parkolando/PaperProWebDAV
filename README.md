# 리디 페이퍼 프로 WebDAV 확장

리디 페이퍼 프로의 기본 앱(리디 서재)에 **WebDAV 탭**을 더해 주는 Xposed 모듈이에요.
NAS나 개인 서버에 둔 책을 기기에서 바로 골라 받고, 리디의 원래 책장과 뷰어로 읽을 수 있어요.

> 리디(RIDI)와는 관계없는 비공식 확장이에요. 기기 소프트웨어를 고치는 작업이 필요하기 때문에, 아래 [꼭 읽어 주세요](#꼭-읽어-주세요)를 먼저 확인해 주세요.

## 무엇이 달라지나요

- 상단 메뉴(내 서재 · 구매 목록 · 서점 · 셀렉트) 옆에 **WebDAV** 탭이 생겨요.
- 서버 폴더를 리디 책장과 같은 모양으로 둘러보고, 책을 누르면 받아서 바로 열어요.
- 받는 동안에는 리디 앱이 원래 쓰는 **책별 다운로드 표시**(대기 · 진행률)가 표지 위에 나와요.
- 폴더마다 **전체 다운로드** 버튼이 있어요. 받는 중에는 **전체 취소**로 바뀌어요.
- 같은 폴더에서 받은 책은 리디에서 구매한 시리즈처럼 **한 칸으로 묶여요**("총 N 권").
- EPUB 제목과 표지를 리디 앱보다 조금 더 잘 읽어요. (EPUB 3 방식 표지, 여러 개의 제목이 든 파일 등)
- 설정 > 전원/보안에 **리커버리로 재부팅**, **fastboot 모드로 재부팅**이 생겨요.

EPUB, PDF, CBZ, ZIP, TXT 파일을 받을 수 있어요. 서버의 파일을 고치거나 지우는 요청은 보내지 않아요.

## 지원하는 기기

| 항목 | 조건 |
| --- | --- |
| 기기 | 리디 페이퍼 **프로** (1세대 · 3세대 등 다른 기기는 지원하지 않아요) |
| 소프트웨어 | **1.6.5** (리디 앱 `P213_1.6.5`, 빌드 20240816) |
| PC | Windows 10/11 (USB 케이블 필요) |

리디 앱 내부 구조에 맞춰 만들었기 때문에 **1.6.5에서만 동작해요.** 다른 버전에서는 모듈이 스스로 꺼지고 WebDAV 탭이 나타나지 않아요. 버전은 기기의 설정 > 기기 설정 > 기기 정보에서 볼 수 있어요.

## 꼭 읽어 주세요

- 이 확장을 쓰려면 기기를 **루팅**하고 **Xposed 프레임워크**를 설치해야 해요. 시스템 파일을 바꾸는 작업이라 드물게 부팅이 안 되거나 데이터가 지워질 수 있어요.
- 소프트웨어를 변조하면 유상 수리 또는 수리 거부 사유가 될 수 있어요.
- 생길 수 있는 문제는 누구도 책임져 드리지 못해요. 중요한 파일은 먼저 PC에 백업해 주세요.
- 만일을 대비해 [순정 펌웨어](#순정으로-되돌리기-벽돌-대비)를 함께 올려 두었어요. 시작하기 전에 미리 받아 두면 좋아요.

## 설치

이 확장에 꼭 필요한 것만 설치해요. 순서는 **① ADB와 루트 열기 → ② Xposed 프레임워크 → ③ WebDAV 확장**이에요. 30분쯤 걸려요.

### 이미 루팅한 기기라면

PaperProKitchen의 어떤 이미지를 썼든, 이미 되어 있는 단계는 건너뛰면 돼요. 기기 소프트웨어가 1.6.5여야 하는 것은 똑같아요.

| 지금 기기 상태 | 시작할 곳 |
| --- | --- |
| ADB와 루트가 이미 있어요 (올인원 · 라이트 · basic 이미지, 리파티션 도구) | 1단계를 건너뛰고 [2단계](#2단계-xposed-프레임워크-설치)부터 해요. |
| Xposed 프레임워크까지 설치되어 있어요 (올인원 이미지는 함께 설치돼요) | [3단계](#3단계-webdav-확장-설치)만 하면 돼요. |
| ADB만 열려 있고 루트가 없어요 ("ADB만" 이미지) | [1단계](#1단계-adb와-루트-열기)부터 해요. Xposed 프레임워크를 설치하려면 루트가 필요하기 때문이에요. |

- ADB는 PC에서 `adb devices`를 입력했을 때 시리얼 번호와 `device`가 나오면 열려 있는 거예요.
- Xposed 프레임워크는 Xposed Installer(앱 서랍이 있다면 거기서 열 수 있어요)의 [프레임워크] 화면에서 `현재 시스템` 칸에 버전 숫자가 보이면 설치되어 있는 거예요. 숫자가 보이지 않거나 Xposed Installer가 없다면 2단계부터 해 주세요.
- 건너뛰는 단계에서 쓰는 파일은 받지 않아도 돼요. 3단계만 한다면 `paper-webdav-1.0.0.apk` 하나면 충분해요.

### 파일을 받고 작업 폴더 만들기

Git이나 개발 도구는 필요 없어요. 이 저장소를 통째로 내려받을 필요도 없고, 위 표의 **파일 세 개만** 받으면 돼요. Windows 11 기준으로 설명할게요.

1. **파일을 받아요.** 표의 링크를 누르면 릴리스 페이지가 열려요. 페이지 아래쪽 **Assets** 목록에서 파일 이름을 누르면 내려받기가 시작되고, 보통 `다운로드` 폴더에 저장돼요.
   - 목록에 함께 보이는 `Source code (zip)`, `Source code (tar.gz)`는 받지 않아요. 설치에 필요한 파일이 들어 있지 않기 때문이에요.
2. **압축을 풀어요.** `다운로드` 폴더에서 `PaperProKitchen_r13_2.zip`을 오른쪽 클릭하고 [압축 풀기...]를 눌러요. 풀 위치를 `C:\paperpro`로 바꾸고 [압축 풀기]를 눌러요.
   - 꼭 이 위치가 아니어도 되지만, 이름에 한글이나 빈칸이 없는 짧은 경로를 권해요. 명령을 입력할 때 실수할 일이 줄어들기 때문이에요.
   - 압축 파일을 더블클릭해서 안을 들여다보는 것만으로는 안 돼요. 반드시 풀어 주세요.
3. **APK 두 개를 같은 폴더로 옮겨요.** `XposedInstaller_2.7_experimental1.apk`와 `paper-webdav-1.0.0.apk`를 `C:\paperpro` 폴더로 끌어다 놓아요. 다 하고 나면 폴더가 이렇게 보여요.
   ```text
   C:\paperpro
   ├─ bin
   ├─ drivers
   ├─ images
   ├─ _start_cmd.cmd
   ├─ _add_vendor_to_adb_usb_ini.cmd
   ├─ XposedInstaller_2.7_experimental1.apk
   ├─ paper-webdav-1.0.0.apk
   └─ (그 밖의 파일들)
   ```
   파일 이름 끝의 `.cmd`, `.apk`가 보이지 않을 수 있어요. Windows가 확장자를 숨겨서 그런 것이니 그대로 두면 돼요.

### 명령 창 여는 법

아래 단계에 나오는 회색 상자의 명령은 **명령 창**에 입력해요.

1. `C:\paperpro` 폴더의 **`_start_cmd.cmd`를 더블클릭**해요. "Windows의 PC 보호"라는 파란 창이 뜨면 [추가 정보]를 누른 다음 [실행]을 눌러요.
2. 검은 창이 열리고 `C:\paperpro>`라는 글자가 보이면 준비된 거예요. 이 창은 처음부터 `C:\paperpro` 폴더에서 열리기 때문에, 폴더를 옮겨 다니는 명령은 몰라도 돼요.
3. 명령은 **한 줄씩** 넣어요. 이 문서의 명령 한 줄을 복사하고, 검은 창 안에서 마우스 오른쪽 버튼을 누르면 붙여 넣어져요. 그다음 Enter 키를 눌러요.
4. 실행이 끝나면 `C:\paperpro>`가 다시 나타나요. 그때 다음 줄을 넣어요.

알아 두면 좋은 점이 있어요.

- **반드시 `_start_cmd.cmd`로 연 창을 써요.** 시작 메뉴에서 여는 명령 프롬프트나 PowerShell에서는 `adb`, `fastboot`를 찾지 못해요. 이 파일이 `bin` 폴더의 프로그램을 쓸 수 있게 준비해 주기 때문이에요.
- 창을 닫았다면 `_start_cmd.cmd`를 다시 더블클릭하면 돼요. 이어서 하던 단계부터 계속하면 돼요.
- 기기를 껐다 켜는 단계가 있어도 창은 그대로 열어 두어도 돼요.

소스 코드를 받아 직접 빌드하고 싶다면 [개발 문서](docs/DEVELOPMENT.md#소스-받기)를 봐 주세요. 설치만 할 거라면 필요 없어요.

### 1단계. ADB와 루트 열기

순정 기기는 PC에서 앱을 설치하는 통로(ADB)가 막혀 있고, Xposed 프레임워크를 설치하려면 루트 권한이 필요해요. 이 부분은 limerainne 님의 [PaperProKitchen](https://github.com/limerainne/PaperProKitchen)을 사용해요.

PaperProKitchen에는 이미지가 여러 종류 있는데, 여기서는 **basic** 이미지만 써요. 런처나 다른 앱 없이 ADB와 루트만 열어 주기 때문이에요. 자세한 설명과 그림은 [PaperProKitchen 설치 문서](https://github.com/limerainne/PaperProKitchen/blob/master/docs/INSTALLATION.md)에 있고, 요약하면 이래요.

1. **드라이버를 설치해요.** 파일 탐색기에서 `C:\paperpro\drivers\GoogleUSBDriver` 폴더를 열고, `android_winusb.inf`를 오른쪽 클릭해서 [설치]를 눌러요. [설치]가 보이지 않으면 먼저 [추가 옵션 표시]를 눌러요.
2. **기기를 완전히 꺼요.** 전원 버튼을 길게 누르고 [확인]을 눌러요. USB 케이블은 PC에 연결해 둬요.
3. **fastboot 모드로 켜요.** 전면 **오른쪽 위 페이지 버튼**과 **전원 버튼**을 함께 누르고 있다가, 전원 버튼 옆 LED가 초록에서 흰색(또는 노랑)으로 바뀌면 손을 떼요. 화면은 바뀌지 않아요.
4. **기기가 잡혔는지 확인해요.** 여기서부터는 [명령 창](#명령-창-여는-법)에 입력해요.
   ```cmd
   fastboot devices
   ```
   시리얼 번호와 `fastboot`가 한 줄 나오면 돼요.
5. **basic 이미지로 부팅해요.**
   ```cmd
   fastboot boot images\openlib_r13_basic.img
   ```
   화면이 몇 번 깜빡이고 "루트 도구 설치 중"이 나온 뒤 저절로 다시 켜져요.
6. **서재 화면이 뜨면 ADB를 확인해요.**
   ```cmd
   adb devices
   ```
   시리얼 번호와 `device`가 나오면 성공이에요. 목록이 비어 있으면 `_add_vendor_to_adb_usb_ini.cmd`를 실행한 뒤 다시 해 보세요.

basic 이미지는 ADB를 켜고 SuperSU(루트)를 설치하는 것 말고도 부트 이미지와 리커버리, 일부 시스템 앱을 고쳐요. 무엇이 바뀌는지는 [PaperProKitchen의 차이점 문서](https://github.com/limerainne/PaperProKitchen/blob/master/docs/DIFFERENCES.md)에 정리되어 있어요.

### 2단계. Xposed 프레임워크 설치

1. **Xposed Installer를 설치하고 열어요.** 순정 페이퍼 프로에는 앱 목록 화면이 없어서 PC에서 명령으로 열어야 해요.
   ```cmd
   adb install XposedInstaller_2.7_experimental1.apk
   adb shell am start -n de.robv.android.xposed.installer/.WelcomeActivity
   ```
   PaperProKitchen의 올인원이나 라이트 이미지처럼 **앱 서랍**이 설치된 기기라면, 둘째 줄 대신 앱 서랍에서 **Xposed Installer**를 눌러 열어도 돼요.
2. 기기 화면에서 **[프레임워크]**를 눌러요. "Be careful!" 경고가 뜨면 읽고 [확인]을 눌러요.
3. **[Xposed 프레임워크 설치 및 업데이트]**를 눌러요. 루트 권한을 묻는 창이 뜨면 허용해 주세요. 설치 방식은 기본값인 `Classical (write to /system directly)` 그대로 두면 돼요.
4. **[기본 재시작(권장)]**을 눌러 다시 켜요.

다시 켜진 뒤 같은 화면을 열었을 때 `현재 시스템` 칸에 `app_process 58`, `XposedBridge.jar 54`가 보이면 잘 설치된 거예요.

### 3단계. WebDAV 확장 설치

1. **확장을 설치하고 Xposed Installer를 다시 열어요.**
   ```cmd
   adb install paper-webdav-1.0.0.apk
   adb shell am start -n de.robv.android.xposed.installer/.WelcomeActivity
   ```
   앱 서랍이 있는 기기라면 여기서도 둘째 줄 대신 앱 서랍에서 Xposed Installer를 열면 돼요.
2. **[모듈 관리]**에 들어가 **리디 WebDAV**에 체크해요. 체크해야 모듈이 켜지기 때문이에요.
3. **기기를 다시 켜요.** Xposed 모듈은 재부팅해야 적용돼요.
   ```cmd
   adb reboot
   ```

다시 켜졌을 때 상단 메뉴에 **WebDAV**가 보이면 설치가 끝났어요.

## 사용하기

### 서버 연결

WebDAV 탭을 처음 누르면 설정 창이 떠요. 나중에는 **설정 > 파일 관리 > WebDAV 설정**에서 바꿀 수 있어요.

| 항목 | 내용 |
| --- | --- |
| 폴더 주소 | 책이 들어 있는 폴더 주소예요. 예: `https://webdav.example.com:5006/books/` |
| 사용자 이름 · 비밀번호 | 서버 계정이에요. 로그인이 필요 없는 서버라면 비워 두세요. |

서버는 다음 조건을 만족해야 해요.

- **`https://` 주소를 권해요.** 인터넷을 거쳐 접속하는 서버라면 반드시 HTTPS여야 해요.
- **집 안의 서버는 `http://`도 돼요.** 단, 주소가 내부망의 사설 IP(`192.168.x.x`, `10.x.x.x`, `172.16.x.x`~`172.31.x.x`)일 때만 연결해요. HTTP는 비밀번호가 암호화되지 않은 채 전송되기 때문에, 바깥 주소로는 일부러 막아 두었어요.
- **HTTPS라면 기기가 신뢰하는 인증서가 필요해요.** Let's Encrypt 인증서로 확인했어요. 직접 만든(자체 서명) 인증서는 쓸 수 없어요.
- 로그인은 **기본 인증(Basic)** 또는 익명 접속만 돼요.
- 주소가 다른 곳으로 넘어가는(리디렉션) 서버라면 **최종 주소**를 입력해 주세요.

비밀번호는 기기의 키 저장소에 든 키로 암호화해서 저장해요. 설정 파일만 들여다봐서는 알 수 없어요. 다만 루팅한 기기에서 루트 권한을 가진 다른 앱까지 막아 주지는 못해요.

### 책 받기

- **폴더**를 누르면 들어가고, 왼쪽 위 **상위**(또는 뒤로 버튼)로 올라가요.
- **책**을 누르면 받은 뒤 바로 열려요. 이미 받은 책은 곧바로 열려요.
- 받는 중이거나 기다리는 책을 다시 누르면 **그 책만 취소**돼요.
- **전체 다운로드**는 그 폴더에서 아직 받지 않은 책을 모두 받아요. 한 권씩 차례로 받아요.
- 받은 책은 리디의 **내 서재**에 들어가요. 읽던 위치, 책갈피 같은 기능은 리디 앱 그대로예요.
- 파일 저장 위치는 설정 > 파일 관리 > 책 다운로드 위치 변경에서 고른 저장소에요. SD 카드를 선택했으면 거기에 저장돼요.

앱이 꺼지면 남은 대기열은 사라져요. 다시 들어가서 받으면 돼요.

### 시리즈로 묶이는 기준

**같은 서버 폴더에 있는 책은 한 시리즈**로 보고, 책장에서 한 칸으로 묶어요. 그래서 서버에는 **작품마다 폴더를 하나씩** 만들어 주세요.

```text
books/
├─ 작품 A/
│  ├─ 작품 A 1권.epub
│  └─ 작품 A 2권.epub
└─ 작품 B/
   └─ 작품 B.cbz
```

- 묶음 이름은 **폴더 이름**이에요.
- 그 폴더에서 받은 책이 **2권 이상**일 때 묶여요.
- 권 순서는 EPUB 안의 시리즈 순번(EPUB 3 `group-position`, calibre `series_index`)을 먼저 따르고, 없으면 **파일 이름 순서**예요. 이름 속 숫자는 수로 비교해서 2권이 10권보다 앞에 와요.
- 책장에는 리디의 구매 시리즈처럼 **마지막 권**이 대표로 보여요.
- 한 폴더에 여러 작품을 섞어 두면 모두 한 묶음이 되니 주의해 주세요.
- 이 기능이 생기기 전에 받아 둔 책은 그 폴더를 한 번 열면 묶여요.

### 재부팅 메뉴

**설정 > 전원/보안** 목록 맨 아래에 두 항목이 있어요. 누르면 한 번 더 물어본 뒤 다시 시작해요.

- **리커버리로 재부팅**
- **fastboot 모드로 재부팅**: PC에서 `fastboot reboot`를 입력하면 원래대로 켜져요.

## 업데이트

새 버전 APK를 받아 덮어 설치하고 다시 켜면 돼요.

```cmd
adb install -r paper-webdav-x.y.z.apk
adb reboot
```

기기 소프트웨어를 업데이트하면 이 확장은 동작을 멈춰요. 1.6.5 전용이기 때문이에요. 시스템이 새로 설치되면서 루트와 Xposed도 함께 풀릴 수 있어요.

## 문제가 생겼을 때

| 증상 | 확인할 것 |
| --- | --- |
| WebDAV 탭이 안 보여요 | Xposed Installer의 [프레임워크]에 버전 숫자가 보이는지, [모듈 관리]에 체크했는지, 그 뒤에 재부팅했는지, 소프트웨어가 1.6.5인지 확인해 주세요. |
| HTTPS 인증서 또는 TLS 연결 오류 | 기기의 날짜와 시간이 맞는지, 서버 인증서가 유효한지 확인해 주세요. |
| 접근이 거부되었습니다 (401/403) | 사용자 이름과 비밀번호, 그 계정의 폴더 권한을 확인해 주세요. |
| http:// 연결은 내부망(사설 IP) 서버에서만 허용됩니다 | `http://` 주소가 내부망 주소가 아니에요. 바깥에서 접속하는 서버라면 `https://` 주소를 입력해 주세요. |
| 서버가 다른 주소로 이동시킵니다 | 브라우저로 열었을 때 최종적으로 표시되는 주소를 입력해 주세요. |
| 폴더 목록이 너무 큽니다 | 한 폴더에는 5,000개까지 표시해요. 하위 폴더로 나눠 주세요. |
| 표지가 글자로만 나와요 | EPUB 안에 표지 정보가 없는 파일이에요. 읽는 데에는 문제가 없어요. |
| `adb devices`가 비어 있어요 | `C:\paperpro` 폴더의 `_add_vendor_to_adb_usb_ini.cmd`를 더블클릭해서 실행하고, 케이블과 포트를 바꿔 보세요. |
| `'adb'은(는) 내부 또는 외부 명령 ... 이 아닙니다` | `_start_cmd.cmd`로 연 창이 아니에요. 창을 닫고 `_start_cmd.cmd`를 더블클릭해서 다시 열어 주세요. |
| APK를 설치할 때 파일을 찾을 수 없다고 나와요 | APK가 `C:\paperpro` 폴더에 있는지, 파일 이름이 명령에 쓴 것과 같은지 확인해 주세요. 명령 창에 `dir *.apk`를 입력하면 그 폴더에 있는 APK 이름이 나와요. |

모듈이 남기는 기록은 이렇게 볼 수 있어요. `hooks ready`가 보이면 정상적으로 켜진 거예요.

```cmd
adb logcat -d | findstr PaperWebDAV
```

## 지우기

- **확장만 지우기**: 받아 둔 책은 서재에 그대로 남아요.
  ```cmd
  adb uninstall dev.paper.webdav
  adb reboot
  ```
- **Xposed까지 지우기**: Xposed Installer의 [프레임워크]에서 [Xposed 프레임워크 제거]를 누르고 다시 켠 다음, `adb uninstall de.robv.android.xposed.installer`를 입력해요.
- **루팅 전으로 완전히 되돌리기**: 아래 순정 펌웨어를 사용해요.

## 순정으로 되돌리기 (벽돌 대비)

부팅이 안 되거나 처음 상태로 돌아가고 싶을 때를 위해 **1.6.5 순정 펌웨어**를 [`firmware-1.6.5P` 릴리스](https://github.com/Parkolando/PaperProWebDAV/releases/tag/firmware-1.6.5P)에 올려 두었어요. 공식 업데이트를 설치한 직후의 파티션을 그대로 떠 낸 파일이에요.

| 파일 | 내용 | SHA-256 |
| --- | --- | --- |
| `boot-1.6.5P-stock.img` | 부트 | `80cbfdba29c8b0a48a8c2c99b396795f8b8ae309b177bf690b35413e144d30ad` |
| `system-1.6.5P-stock.img` | 시스템 (약 384 MB) | `f4816e8af34c66c0ae6cd14e7cd6d71cb053b77aecbf40e0f353d8e7c48a8f2f` |
| `recovery-1.6.5P-stock.img` | 리커버리 | `eacb95da95f9112b8ef2ba36e6f70815a0886813e541312be30a8e0e3918df70` |

받은 파일이 온전한지는 `certutil -hashfile 파일이름 SHA256`으로 확인할 수 있어요. 값이 다르면 쓰지 말고 다시 받아 주세요. 깨진 파일을 넣으면 더 큰 문제가 생기기 때문이에요.

되돌리는 방법은 [PaperProKitchen의 순정 복구 문서](https://github.com/limerainne/PaperProKitchen/blob/master/docs/BACK_TO_STOCK.md)와 같아요.

0. 받은 펌웨어 파일 세 개를 설치할 때 만든 `C:\paperpro` 폴더에 넣고, [명령 창](#명령-창-여는-법)을 열어요. 그 폴더가 없다면 Google이 배포하는 [Platform-Tools](https://developer.android.com/tools/releases/platform-tools)와 [USB 드라이버](https://developer.android.com/studio/run/win-usb)를 받아서 써도 돼요.
1. 기기를 **fastboot 모드**로 켜요. [1단계](#1단계-adb와-루트-열기)의 버튼 조합을 쓰면 돼요.
2. 세 파일을 차례로 넣어요. 파티션 이름과 파일 이름이 서로 맞는지 꼭 확인해 주세요.
   ```cmd
   fastboot flash boot boot-1.6.5P-stock.img
   fastboot flash system system-1.6.5P-stock.img
   fastboot flash recovery recovery-1.6.5P-stock.img
   fastboot reboot
   ```
   시스템 파일은 크기 때문에 몇 분 걸려요. 끝났다는 메시지가 나올 때까지 케이블을 뽑지 말아 주세요.

알아 둘 점이 있어요.

- 시스템 파티션을 통째로 덮어쓰기 때문에 Xposed, SuperSU, 고쳐진 시스템 파일이 모두 순정으로 돌아가요.
- 받아 둔 책과 설정 같은 **사용자 데이터는 지우지 않아요.** 완전히 처음 상태로 만들려면 되돌린 뒤 **설정 > 전원/보안 > 기기 초기화**를 해 주세요.
- 기기 소프트웨어가 1.6.5보다 **높은 버전**이라면 낮은 버전으로 되돌리면 부팅되지 않을 수 있어요. 그럴때는 리커버리 모드로 부팅해서 공장초기화를 진행해 주세요.
  - **리커버리 모드로 들어가는 법**: fastboot 모드로 켤 때와 똑같이 기기를 끈 상태에서 전면 **오른쪽 위 페이지 버튼**과 **전원 버튼**을 함께 눌러요. LED에 초록 불이 들어오면 **전원 버튼에서만** 손을 떼고, 오른쪽 위 페이지 버튼은 리커버리 화면이 나올 때까지 계속 누르고 있어요.
  - 리커버리 화면에서는 전면 버튼으로 메뉴를 옮기고 전원 버튼으로 골라요. [Factory reset]으로 초기화한 다음 [Reboot]로 빠져나오면 돼요.
- 저장 공간을 **리파티션**한 기기는 파티션 구성까지 되돌려 주지 않아요. 그 경우에는 [리파티션 도구의 안내](https://github.com/limerainne/PaperProKitchen/tree/repart)를 따라 주세요.

## 알아 둘 점

- 서버에서 파일이 바뀌어도 이미 받은 책을 자동으로 다시 받지는 않아요.
- 받기 전에는 표지 대신 파일 이름이 보여요. 표지는 책 안에 들어 있어서 받아야 알 수 있기 때문이에요.
- 저장 공간이 모자라면 받지 않고 실패로 표시해요. 받는 동안에는 화면이 꺼지지 않게 해 둬요.
